# java-attendance-precourse

### 주요 기능
- 출석 (확인)
- 출석 수정
### 세부 기능
- 시작 시간으로 부터 5분 초과  : 지각
- 시작 시간으로 부터 30분 초과, 등교하지 않음 : 결석
- 3*지각 = 결석

- 대상자
  - 경고 대상자: 결석 2회 이상 
  - 면담 대상자: 결석 3회 이상 
  - 제적 대상자: 결석 5회 초과

### 플로우
- 출석 확인 - csv 파일에 이미 들어있는 데이터를 확인하는 거임!!!!!!!!
  - 닉네임을 입력한다.
  - 등교 시간을 입력한다.
  - 출석 확인 안내문을 출력한다 - 12월 05일 화요일 09:59 (출석)

- 출석 수정
  - 닉네임을 입력한다.
  - 수정 날짜를 입력한다. + 수정 날짜가 주말, 또는 공휴일인지 확인한다. 
  - 수정할 시간을 입력한다.
  - 수정 전,수정 후 안내를 출력한다. - 12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!

- 출석 기록 확인
  - 닉네임을 입력한다.
  - 출석 기록을 출력한다.
  - 출석, 지각, 결석 횟수를 출력한다.

- 재적 위험자 확인
  - 재상자들을 출력한다.
  - 결석을 기준으로 내림차순 하여 출력한다.
### 유효 검사
- 출석 확인
  - 등교일이 아닌 경우는 출석할 수 없다.
- 닉네임
  - 존재하지 않는 경우
- 출석 수정
  - 미래 날짜로 수정하는 경우
  - 주말 또는 공휴일에 수정하는 경우
  - 08:00~23:00 등교 시간이 아닌 경우
  - 이미 출석했는데 다시 수정할 경우

### 주의할 점
- 24시간 형식만 가능하다.
- 캠퍼스 운영 시간은 매일 08:00~23:00이다.
- 주말, 공휴일에는 출석을 받지 않는다.
- 교육 시간은 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00이다.
